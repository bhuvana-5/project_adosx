# AdosX Cross-System Reconciliation

A small full-stack reconciliation application for comparing records from
System A and System B while enforcing tenant isolation.

## Tech Stack

- Backend: Python + Django
- Database: SQLite
- Frontend: React + Vite
- Testing: Django SimpleTestCase
- Data: CSV
